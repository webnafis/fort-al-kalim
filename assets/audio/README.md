# Local Audio Assets

Place your app-specific audio files here.

Examples:
- `bgm_battle.mp3` (Background music during duels)
- `bgm_menu.mp3` (Main menu music)
- `hit.mp3` (Sound effect when damaging an enemy fort)
- `click.mp3` (General UI button click)

**Important Note:** 
Vocabulary word audio files should NOT be placed here. Those will be streamed directly from your GitHub CDN to keep the app's install size as small as possible!
